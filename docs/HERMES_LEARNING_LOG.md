# Hermes Learning Log

This file records validated operating lessons from agent-assisted work. It is not a scratchpad and must not be used to convert assumptions into facts.

## Rules

- Add an entry only after a real outcome is observed or a failure is reproduced and understood.
- Separate evidence from interpretation.
- Never include credentials, private customer data, or sensitive production payloads.
- Prefer lessons that improve future system behavior, review quality, recovery time, conversion reliability, or operator throughput.
- If the conclusion is still uncertain, mark it `provisional` and state what evidence is missing.

## Entry Template

### YYYY-MM-DD — Short lesson title

**Status:** validated | provisional  
**System:** repository / integration / outbound / commerce / analytics / infrastructure / other  
**Trigger:** What task, incident, experiment, or deployment produced the learning?  
**Observed outcome:** What actually happened?  
**Evidence:** Tests, logs, metrics, review findings, or reproducible behavior.  
**Root cause / pattern:** What generalized pattern is supported by the evidence?  
**System change:** What should future agents or operators do differently?  
**Follow-up:** Any unresolved validation or monitoring requirement.
